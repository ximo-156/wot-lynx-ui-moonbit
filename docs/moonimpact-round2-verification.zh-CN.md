# MoonImpact 第二轮：静态读取器和样式表输入

[English](<moonimpact-round2-verification.md>) | [简体中文](<moonimpact-round2-verification.zh-CN.md>)

本记录是本地工作区验证，并非发布、远程 CI 结果，也不保证在任意项目上选择性测试的安全性。[初始 MVP 记录](<moonimpact-verification.zh-CN.md>)单独保留。

## 新增覆盖

- 符号化的根目录/模块相对路径：真实的 fs/path/url 导入、受限的不可变路径常量、`process.cwd()`、`__dirname`、静态模块相对 URL 构造及 `fileURLToPath`。
- 仅从支持的单参数、单返回文件系统读取函数体推断读取器包装函数。不会信任任意名为 `read` 或 `ROOT` 的对象。用户声明的 `file_readers` 仍是独立的显式契约。
- CSS/SCSS 导入、Sass 模块/局部文件和静态资源 URL 构成传递证据链，包括受支持的 Vue 内联和外部样式。
- 原始读取将已知的范围外文件视为不透明数据，不会执行其导入。文件系统名称保留字面的 `?`/`#`；只有 CSS URL 语义会移除查询/片段后缀。

## 保留的安全性

变更赋值、遮蔽、URL/包装函数逃逸、额外 I/O 和动态路径仍会要求完整回退。绝不会读取配置的安全根目录之外的文件。路径求值有深度限制；对规范化敏感、包含中间点路径段的 dirname 形式会被刻意拒绝，而非猜测。URL 首尾的控制空白字符及内嵌制表符/换行符不会被当作字面文件系统文件名。导入的样式表内容必须实际分析；无效 UTF-8/不安全的源码输入会阻止执行。样式表歧义、未知预处理器/自定义导入器，以及未解析的输入，仍会显式呈现为不确定性。

计划器仍然不会执行项目代码、修改业务源码或安装依赖。只运行了合成/隔离测试。

## 受控的 unibest 比较

在修改代码前保留了旧可执行文件。旧版本和新版本使用**相同的配置、变更和输入树**连续运行。配对运行前后的内容哈希一致：

```text
6c8e92fce8903e0273c89754083d30fc17fa3e27dc87809c1dc4f6a636b725f4
```

两个变更输入是退款页面和全局主题 SCSS。自初始 MVP 快照以来，目标项目已独立演进，因此不得将其历史上的 319 个不确定性项直接与本次测量比较。

| 指标 | 旧可执行文件 | 新可执行文件 |
| --- | ---: | ---: |
| 已分析的源码 | 623 | 628（包括 CSS/SCSS） |
| 已知依赖边 | 2,244 | 2,358 |
| 测试清单 | 296 | 296 |
| 不确定性观察项 | 334 | 267 |
| 动态/不支持的文件路径观察项 | 196 | 146 |
| 被排除的源码观察项 | 22 | 1 |
| 实际策略 | full | full |
| 选中的测试清单 | 296 | 296 |

在不改变目标项目、也不放宽未知输入回退规则的情况下，**不确定性观察项减少了 67 个**。这体现的是输入覆盖的改善，**并非声称全项目 CI 现在运行更少的测试**。单次计划耗时分别约为 0.74s 和 0.86s；额外分析有成本，这些数据并非统计性能基准。

剩余观察项包括目录/存在性查询（75）、动态路径（146）、未解析的文件输入（37）、保守遮蔽（5）、Less 样式块（2）、一个被排除的模块，以及一个未解析的字体 URL。最后一项是根目录 iconfont CSS 对一个在该相对位置并不存在的字体的引用；计划器没有改写业务资源路径，也没有隐藏问题。闲置文件和不完整的配置范围需要项目所有者审查，不会自动豁免。

## 回归证据

在接口生成、格式化、检查和重新构建之后：

- 原生单元测试：**529 个通过**。
- MoonImpact CLI 回归：**23 个通过**。
- 原生进程/报告安全性回归：**15 个通过**。
- 原有 moonlint CLI 回归：**207 个通过**。
- 仓库自检 lint：没有发现项或源码失败。

可选的真实 Vitest 合成冒烟测试也通过了：费用和主题测试选择性运行；刻意引入的费用缺陷在选择性运行和完整运行中均被捕获。演示读取器现在使用推断出的 `ROOT` + `read(file)` 包装函数，无需读取器名称信任条目。[演示](<../examples/impact-demo/README.zh-CN.md>)也展示了 palette CSS -> theme CSS -> 测试链。基于依赖的选择是保守的；并不声称输入变化时每个选中测试都会失败。
