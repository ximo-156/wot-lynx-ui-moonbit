本记录是本地工作区验证，并非发布、远程 CI 结果，也不保证在任意项目上选择性测试的安全性。[第三轮记录](<moonimpact-round3-verification.zh-CN.md>)覆盖 JS/TS 引擎，仍然有效；本记录增加 MoonBit 前端。后续的[第五轮记录](<moonimpact-round5-verification.zh-CN.md>)使用 `--run` 在同一公开项目上执行这些计划，与完整套件比较，并注入故障来检查选中集合能够捕获什么。

> **2026-11-13 重新验证**（moon 0.1.20261111）：复现了下文所有数字——555 个原生单元测试、38 个 MoonImpact CLI 回归、15 个原生桥接回归、207 个 moonlint CLI 回归、无发现项的仓库自检 lint、只读稳定性套件（6 个测试，MoonBit 模式）、moonbitlang/x 的选中集合（1/19 和 4/19），以及两种仓库计划模式（仅 CLI 变更为 `none`，库变更为选中根包的 `related`）。实际耗时取决于机器：在重新验证机器上，冷缓存配对重测为完整 13.0s / 选中 2.4s（顺序相同，测试数仍为 555 对 0）。远程 CI 仍未启动（账户计费锁定）。

## 新增内容

第二种项目类型，无需任何配置即可生成计划：根目录包含 `moon.mod` / `moon.mod.json` 时，直接从 `moon.pkg` 清单读取包图进行分析。生成计划期间不调用工具链，也不执行项目代码。

- **多模块发现。** 根目录下每个模块描述文件声明一个模块；包基于自身模块解析导入，因此嵌套模块和工作区模块绝不会借用根模块名称。
- **每个导入块均计入。** 普通 `import { … }`、`import { … } for "test"` 和 `#cfg(...)` 条件块均声明依赖，因为仅测试依赖仍然决定该包的测试能否观察到变更。先前的单块解析器曾静默丢弃 moonbitlang/x 中 `encoding` 的 `for "test"` 导入方；测量发现这一遗漏后，才编写了多块解析器。
- **归属和反向遍历。** 变更文件选中目录前缀最长的包（模块根包拥有其余文件），以及每个传递导入方，包括仅测试导入。运行器以 `.` 指定模块根包。
- **保留建议性契约。** 无法解析的清单、缺失的模块描述文件、不属于任何包的变更，或任何清单/描述文件变更，都会请求所有包；I/O 失败会阻止执行。
- **符号链接文档不再阻止所有计划。** 只有在内容可能相关时——源码、样式表或清单——才拒绝非普通文件。moonbitlang/x 中四个链接形式的 `README.md` 文件此前阻止了所有计划；链接文档属于成员数据。
- **纯计划核心。** 计划器拆分为文件系统包装层和对已收集成员清单执行的纯函数，因此无需工具链即可对图、策略和证据链进行单元测试。

## 仓库测量

本仓库本身是多模块工作区：根包、`cmd/main`、`cmd/impact` 及四个示例模块。执行 `moon clean` 后的冷缓存比较：

| 运行 | 实际耗时 | 测试数 |
| --- | --- | --- |
| 完整套件（`moon test`） | 5.4s | 555 |
| 仅 CLI 变更（`moon test cmd/impact`） | 2.1s | 0——计划为 `none` |

库变更（`impact_plan.mbt`）选中根包并运行其 555 个测试，这是如实的答案：CLI 包导入该库，因此其构建受影响，但它们不包含测试。

## 自动化覆盖

- 原生单元套件：**555 个通过**（12 个新增：包含多块和格式错误形式的清单解析、模块发现及排序、按模块解析说明符、归属、包图边、策略、证据链、全局输入、缺失和空变更）。
- MoonImpact CLI 回归：**38 个通过**（5 个新增：无需配置的原生 MoonBit 计划、仅 CLI 变更计划为 `none`、描述文件变更请求所有包、选中包的 `moon test` argv，以及既无配置也无模块时的明确错误）。
- 原生桥接回归：**15 个通过**；原有 moonlint CLI 回归：**207 个通过**；仓库自检 lint：无发现项。
- 只读稳定性套件在**两种**模式下均通过：将本仓库作为 MoonBit 模块（无配置），以及使用配置的 JS/TS 项目——变更输入扫描、重复运行逐字节一致、Git 输入模式、退化输入、仅创建报告及耗时上限。CI 现在运行这两项门禁。

## 保留的边界

生成计划只读取清单和目录树；不求值 MoonBit 代码、不解析类型级依赖，也不对条件编译建模，仅统计导入块。计划提供建议：并不声称输入变化时每个选中包都会失败，选择性缩减能力取决于具体项目。
